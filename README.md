# Kingdom Stand

**Платформы:** PC, Android, WebGL  
**Жанр:** Tower Defense  
**Стек:** Unity 6.3, C#, URP

---

## Особенности проекта

- Архитектура на основе **DI-контейнера**.
- **Система загрузки ресурсов и конфигов** (Resources, ScriptableObjects).
- Интерфейс на основе **MVP** с анимациями через **DOTween**.
- Геймплейные сущности, спроектированные на основе комбинации **ООП и ECS-подхода**.
- **Геймплейный цикл уровней**.
- **ИИ** на основе **машины состояний**.

---

## Структура проекта

Основная логика и контент проекта вынесены в отдельную папку, чтобы отделить их от сторонних ассетов.

```text
Assets/
  _Project/                     # Основная папка проекта
    ...                         # Графические и звуковые ассеты
    Develop/                    # Основной код (C#)
      Editor/                   # Редакторские скрипты
      Runtime/                  # Игровая логика
        Configs/                # Структура конфигов
        Gameplay/               # Геймлейная часть
          EntitiesCore/         # Структура сущностей (ESC + ООП)
          Features/             # Геймплейные фичи, ИИ
          GameMode/             # Логика игрового режима
          Infrastructure/       # Точка входа, зависимости, игровой цикл
        Infrastructure/         # Точка входа в проект, DI контейнер
        Meta/                   # Главное меню, уровни, прогрессия
        UI/                     # MVP-модули интерфейса: Presenters, Views, Popups
    Prefabs/                    # Префабы
    Resources/                  # Динамически загружаемые ресурсы
    Scenes/                     # Сцены
  ...                           # Сторонние ассеты, плагины, пакеты, другие настройки
```

## Архитектура

### Dependency Injection

- Для управления зависимостями используется свой облегченный **DI-контейнер**.
- Сервисы регистрируются в контейнере и прокидываются в нужные места.

### Интерфейс на базе MVP

- **Model** — данные и сервисы.
- **View** — MonoBehaviour-компоненты, отвечающие за отображение интерфейса и ввод пользователя.
- **Presenter** — C#-слой, который:
  - Подписывается на события View.
  - Работает с игровыми сервисами и данными.
  - Обновляет View.

Анимации UI реализованы через **DOTween** (попапы).

### Геймплейные сущности: ООП + ECS-подход

- Сущности (башни, враги, снаряды) спроектированы с разделением:
  - **Данные**  — в виде C#-классов (компонентов).
  - **Логика** — вынесена в отдельные системы на основе ООП.

Большинство компонентов использует свой реактивный тип данных - ReactiveVariable (generic).

### ИИ на основе машины состояний

- Сущности управляются через **иерархическую машину состояний**:
  - Состояния: `MoveToTarget`, `FindTirger`, `Attack` и т.п.
  - Переходы между состояниями определяются условиями.
